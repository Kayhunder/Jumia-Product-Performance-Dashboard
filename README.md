# Jumia-Product-Performance-Dashboard
The goal of this project is to create an interactive Excel dashboard that provides insights into the  performance of products listed on Jumia. The dashboard should help Jumia and sellers make  better decisions around pricing strategies, promotions, and customer engagement.
	
**Project	**Jumia Product Performance Dashboard
Purpose	Analyze pricing, discounts, customer reviews and ratings.
Cleaning	Removed exact duplicates; converted numeric fields; corrected negative review counts; retained missing ratings/reviews as missing.
Enrichment	Discount Amount, Rating Category, Discount Category, Price Category, High Discount Low Rating, Strong Engagement.
Price Categories	Low <= KSh 500; Medium KSh 501–1,700; High > KSh 1,700.
Key Finding	Higher discounts do not automatically produce higher review engagement.
Key Finding	Rating and review volume have a very weak relationship.
Key Finding	Price and rating have a weak relationship.
Recommendation	Investigate products with high discounts and low ratings rather than relying only on deeper discounts.
Data Limitation	The KSh 16.2M price is an extreme outlier and materially inflates the raw average.
Workbook	Dashboard, Raw Data, Cleaned Data, Analysis, Pivot Summary and README sheets are included.
